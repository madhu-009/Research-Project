# 📊 Financial Determinants of ESG Performance among NIFTY 100 Companies

## 📌 Project Overview

This research project examines the financial determinants influencing **ESG (Environmental, Social and Governance) performance** among NIFTY 100 companies during **2021–2025**.

The study combines **panel data analysis and machine learning techniques** to identify and evaluate the factors associated with ESG performance.

## 🎯 Objectives

- 📊 Analyze financial and firm-specific determinants of ESG performance
- 🔎 Examine relationships between financial variables and ESG scores
- 📈 Perform exploratory and statistical analysis of panel data
- 🤖 Apply machine learning to identify important ESG determinants
- 🧠 Use SHAP for model explainability and feature importance
- 💡 Derive insights into the key factors influencing ESG performance

## 🛠️ Analysis Performed

### 1. Data Preparation
- Data cleaning and preprocessing
- Missing value treatment
- Variable transformation
- Panel data structuring
- Outlier treatment

### 2. Exploratory Data Analysis
- Descriptive statistics
- Correlation analysis
- Distribution analysis
- Multicollinearity assessment using VIF
- Visualization of key variables

### 3. Panel Data Analysis
- Fixed Effects Model
- Random Effects Model
- Model comparison and diagnostics
- Robustness analysis

### 4. Machine Learning
- Random Forest Regression
- Group-based train-test splitting
- Model evaluation using R², RMSE and MAE
- Feature importance analysis

### 5. SHAP Explainability
- SHAP feature importance
- Identification of key ESG determinants
- Interpretation of individual feature contributions
- Ranking of important financial and firm-specific variables

## 📊 Key Variables

The analysis considers selected financial and firm-specific characteristics such as:

- ESG Score
- Return on Assets (ROA)
- Return on Equity (ROE)
- Debt-to-Equity Ratio
- Firm Size
- Revenue Growth
- Market Capitalization
- Beta
- Dividend Payout
- Promoter Holding
- Firm Age
- Other financial indicators
